# 26-Week Engineering Portfolio Roadmap

## Goal

Build three production-style projects that together demonstrate practical engineering capability across software engineering, full-stack development, backend/API development, cloud engineering, AI engineering, DevOps, infrastructure as code, database design, authentication and authorization, testing, monitoring, observability, security, and troubleshooting.

## Portfolio overview

| Project | Focus | Planned timeline |
|---|---|---|
| FlowDesk | Production-grade SaaS application | Weeks 2-8 |
| DocuMind | AI document intelligence platform | Weeks 9-15 |
| DeployFlow | Cloud & DevOps deployment platform | Weeks 16-21 |

## Phase 0 — Portfolio foundation

### Week 1 — Portfolio setup

- Create GitHub repositories for each project
- Set up the portfolio dashboard
- Define repository standards and branch conventions
- Define issue and pull request conventions
- Create README templates
- Define Azure architecture direction
- Estimate Azure costs
- Review Azure for Students limits and free/low-cost options

## Engineering lifecycle

Plan → Design → Develop → Test → Secure → Deploy → Monitor → Troubleshoot → Improve

## Portfolio principles

- Prefer production-oriented practice over toy implementations
- Build for realistic engineering trade-offs
- Keep Azure cost-conscious and student-budget aware
- Use structured logs, metrics, and traces where practical
- Document architecture, decisions, and deployment flows
- Never expose secrets or private data in repositories or screenshots
